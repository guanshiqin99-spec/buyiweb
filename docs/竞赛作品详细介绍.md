# 濒危布依语智能词典系统 —— 项目详细介绍

> 参赛方向：北京市大学生数字媒体设计竞赛 B 类（互联网应用及多媒体作品应用类）
> 作品类型：多端互联网应用（Web 大屏 + 微信小程序 + 运营管理后台）

---

## 一、项目概述

布依族是中国人口较多的少数民族之一，主要聚居在贵州、云南等西南省份。布依语属于侗台语系壮傣语支，使用人群日益萎缩，已被列为**濒危语言**。随着汉语普及与人口流动，年轻一代布依族能熟练使用母语的人数逐年下降，语言这一"活的非物质文化遗产"正面临失传危机。

本项目以"抢救濒危语言"为使命，打造一套 **面向布依语言与文化传承的多端数字媒体应用系统**。系统将**词汇查询、短语与谚语学习、民歌欣赏、文化展厅、AI 智能学习**、**发音跟读评测**、**成就成长体系**等功能整合到 Web、微信小程序与运营后台三大终端，用数字化手段为布依族语言文化的记录、学习与传播提供完整闭环。

系统定位社会公益价值，核心叙事为：

> **"从看懂到听懂，再到开口说——用 AI 帮助抢救濒危八音里的最后一道生命。"**

## 二、作品亮点

1. **讲好文化故事**：围绕真实布依族文化素材（八音坐唱、蜡染、农耕、村寨）构建内容，附权威溯源标注，兼具可信度与社会传播价值。
2. **多端协同体验**：Web 大屏承担惊艳的视觉展示，微信小程序承载移动端学习的便捷触达，两端共用同一套后端与数据，展示"一端多屏"的完整技术实力。
3. **AI 深度赋能**：AI 导览员、AI 造句、AI 出题、AI 关联推荐、AI 语音跟读评测，把智能技术真正落进"看—听—说"的学习闭环。
4. **完整成长体系**：徽章、每日任务、学习热力图、能力雷达图、个性化学习建议、成就分享卡，让学习"看得见、可激励、可分享"。
5. **数据可视化叙事**：用柱状图、雷达图、热力图直观呈现学习足迹，让用户的努力与成长一目了然。

## 三、技术架构

### 3.1 整体架构

项目采用 **前后端分离 + 多端共用后端** 的架构：

```text
┌──────────────────────────────────────────────────────────┐
│                       客户端层                             │
├──────────────────┬──────────────────┬────────────────────┼
│  Web 前端 (Vue3) │  微信小程序       │  运营管理后台      │
│  /               │  /pages/*        │  /admin-web/       │
└───────┬──────────┴────────┬─────────┴────────┬───────────┘
        │ HTTPS/Axios       │ 云函数 apiProxy  │ fetch/RBAC
        │                   │   直连后端       │
        └───────────────────┼──────────────────┘
                            ▼
               ┌──────────────────────────┐
               │    NestJS 后端 (3000)    │
               │   /api/miniapp/*         │
               │   /api/admin/*           │
               │   健康检查 / 文档         │
               └─────────────┬────────────┘
                             ▼
               ┌──────────────────────────┐
               │  TypeORM 实体层 (17个)   │
               │  MySQL8 生产 / SQLite 本地│
               └──────────────────────────┘
```

### 3.2 技术栈

| 层级 | 技术 |
|------|------|
| Web 前端 | Vue 3、Vite、Pinia、Vue Router、Axios、原生 CSS 设计系统 |
| 微信小程序 | 原生小程序 + 自定义组件 + 云函数（apiProxy） |
| 后端 | NestJS 11、TypeORM、JWT、RBAC、SSE 流式 |
| 数据存储 | MySQL 8（生产）、SQLite（本地开发/离线兜底） |
| AI 能力 | DeepSeek（流式问答/出题/造句）、Web Speech API / 微信同声传译（语音识别） |
| 部署 | 阿里云 ECS + Nginx + PM2、Cloudflare Pages、Cloudflare Tunnel |

### 3.3 部署架构

- **Web 通道**：浏览器 → Cloudflare Pages（HTTPS）→ Cloudflare Named Tunnel → 阿里云北京 ECS → NestJS
- **小程序通道**：小程序 → 微信云函数 `apiProxy` → 后端 IP（无需配置合法域名）
- **运营后台**：后端静态托管 `/admin-web/`
- **数据安全**：MySQL 仅监听本机端口，敏感字段（密码、手机号）脱敏返回，媒体上传走扩展名白名单校验

## 四、功能详细介绍

### 4.1 词典查询（核心功能）

- **多语种检索**：支持按布依文、拼音、中文释义检索词条，返回词条本体、词性、释义、例句等完整信息。
- **智能相关性排序**：检索结果按"汉义精确 > 前缀 > 包含 > 布依文 > 英文"优先级排序，贴近真实查询意图。
- **联想提示**：输入时提供基于词条本体的智能联想建议。
- **权威溯源**：每条结果标注来源（非遗官网 / 布依词典数据库）与核验状态，增强可信度。

### 4.2 语言学习体系（看）

- **词汇浏览**：按分类浏览词条，支持收藏与复习。
- **短语与谚语**：独立模块展示日常短语与谚语，配有释义与例句。
- **学习卡片**：以卡片形式强化记忆，支持"收藏—回顾"闭环。
- **AI 造句与关联推荐**：选中词条后可一键让 AI 造生活化例句，或推荐 3 个相关词汇展开语义网络。

### 4.3 民歌欣赏（听）

- **民歌资源库**：内置布依族八音坐唱等真实民歌素材，支持列表浏览、封面与详情。
- **音频播放器**：自研播放器组件，含频谱动效、播放控制、收藏与分享。
- **播放记录**：记录收听历史，纳入学习统计。

### 4.4 文化展厅（赏）

- **三大展项**：蜡染、传统工艺、自然生态，图文并茂呈现布依族文化。
- **音频导览**：为展项配置语音讲解，沉浸式了解文化背景。
- **内容关联**：从文化展项可跳转相关民歌、词条，构建"词—文化—民歌—答题"关联链路。

### 4.5 AI 智能助手与评测（说——特色亮点）

- **AI 导览员**：基于 DeepSeek，通过 SSE 流式对话回答布依语与文化相关问题，实时逐字渲染，支持词条问答、文化讲解。
- **AI 发音闯关**：用户跟随布依语词句朗读 → 语音识别（Web Speech API / 微信同声传译）→ 后端基于拼音相似度算法打分 → 分档反馈（标准/不错/接近/再试一次）。将"看"和"听"推进到"开口说"，补齐濒危语言传承的最后一环。
- **AI 五题挑战**：一键生成布依文化选择题，动态扩充题库。
- **全端一致评分**：评分算法统一放在后端（纯函数），小程序与 Web 结果一致、可单元测试、可答辩演示。

### 4.6 答题与学习记录（测）

- **文化答题闯关**：内置非遗主题题库，支持普通答题与 AI 生成题。
- **发音闯关**：以发音评测为核心的新玩法，与答题共用成绩体系。
- **学习记录**：自动记录查询、播放、答题、跟读等行为，时间轴展示成长过程。

### 4.7 成就与成长体系（激励）

- **徽章系统**：根据学习里程碑解锁多种徽章。
- **每日任务**：查词、听歌、答题等任务式引导，附带进度条。
- **数据可视化**：学习热力图（习惯养成）、能力雷达图（多维度均衡）、柱状图（类型分布）。
- **个性化学习建议**：基于学习数据动态生成行动建议，并附跳转入口。
- **成就分享卡**：Canvas 生成"我的布依语学习报告"分享图片，促进传播。

### 4.8 多端体验与可访问性

- **响应式布局**：Web 端适配桌面大屏与移动竖屏，窄屏词条弹窗式详情。
- **深色模式**：白天/夜晚主题一键切换，导航栏颜色随内容自适应。
- **无障碍设计**：键盘导航、ARIA 标注、减少动效偏好支持。
- **离线容错**：学习提醒 Service Worker、API 与音频渐进式缓存，弱网下仍可用。

### 4.9 运营管理与安全

- **内容管理后台**：管理员对词条、短语、谚语、民歌、文化展项、媒体资源、用户进行全量 CRUD，支持 Excel 批量导入。
- **数据看板**：仪表盘统计核心运营数据。
- **权限体系**：管理员 RBAC 角色权限、登录失败锁定、会话管理（登出即令令牌失效）。
- **安全加固**：接口限流防滥用、字段脱敏（手机号 138****1234）、媒体上传白名单、密钥环境变量管理。

## 五、竞品与差异化价值

| 维度 | 本项目 | 传统词典/方言类应用 |
|------|--------|-------------------|
| 语言保护 | 专注于濒危布依语的抢救与传承 | 多为通用语种，无濒危语言聚焦 |
| 内容闭环 | 看、听、说、测、激励一体 | 通常只有查词单一功能 |
| AI 能力 | 问答、造句、出题、发音评测全覆盖 | 无 AI 或仅基础搜索 |
| 多端 | Web + 小程序 + 后台三端协同 | 多为单端 |
| 文化叙事 | 民歌、蜡染、谚语等真实文化素材 | 纯工具，缺文化温度 |
| 社会价值 | 面向少数民族濒危语言保护的公益导向 | 纯商业工具 |

## 六、社会价值与创新意义

布依语正在走向濒危，本项目以数字化、智能化的方式为其注入新的生命力：

- **记录**：将散落的词条、短语、谚语、民歌数字化沉淀为可检索、可共享的数据库。
- **学习**：用友好、立体的多端体验降低学习门槛，吸引年轻一代与外部爱好者。
- **传播**：通过成就分享、文化展厅、民歌与蜡染内容讲好布依族故事，扩大影响力。
- **抢救**：AI 发音跟读评测让学习者敢于"开口说"，这是濒危语言传承中最难、也最关键的环节。

系统的最终目标是：**让每一种正在消失的语言，都有被看见、被喜欢、被说出口的机会。**

## 七、项目规模

- **功能模块**：13 个 Web 页面、20+ 小程序页面、17 个后端数据实体、30+ 套组件。
- **业务接口**：覆盖小程序（15 个模块）、后台（7 个模块）、公共层三大类接口。
- **代码规模**：TypeScript / JavaScript 核心源码合计约 3.9 万行（不含脚本与归档文件）。
- **素材丰富**：内置民歌音频、文化图片、真人语音发音、高清单曲等多媒体素材。
