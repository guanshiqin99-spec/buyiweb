# 布依词典数据来源与参考文献

本文档说明项目词条、短语、谚语、民歌数据的整理依据。所有布依文（拉丁书写）均以 1985 年《布依文方案（修订案）》确立的规范布依文为准（以第一土语为基础、望谟县复兴镇话为标准音），未采用壮文拼写或未经验证的转写。

## 一、拼写规范

| 规范 | 说明 |
| --- | --- |
| 《布依文方案（修订案）》（1985） | 现行布依文书写规范：26 个拉丁字母、32 个声母、87 个韵母、8 个调类；调号 l/z/c/x/s/h/t 标于音节末，第八调不标。以望谟县复兴镇话为标准音 |
| 现代汉语借词调号 | 按望谟话读音另用 y/f/j/q 四个调号拼写（如 feiyjiy 飞机、minfzuf 民族） |

## 三、数据构成

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| 词条 | 715 条 | 按语义体系组织：自然、动物、植物、饮食、服饰、身体、亲属称谓、数词量词、颜色状态、动作、器物场所、虚词代词、地名借词等；每条含布依文、汉义、英文、分类、例句（有例句者）、来源编码 |
| 短语 | 69 条 | 全部为 D1/D2 教材原句（问候、礼貌、问答、日常、节庆等场景） |
| 谚语 | 111 条 | 全部出自 D3《布依族谚语格言选》与 D13 农谚文献，布依文与汉文逐句对照 |
| 民歌 | 3 首（新增） | 好花红（布依语版，D11）、月亮星星歌、高寨家（D1 童谣），均含布依文歌词 |

另有约 470 条词条以"语素组合"方式收录（如 noh mul 猪肉、raanzngvax 瓦房、byal raaiz 花鱼等），其构成语素与修饰语序均有 D1/D2 教材例句直接支撑（如"Noh mul nix waanl dazraaix""Raanz mbaanx sul doc deengl raanzngvax"）。

## 四、质量原则

1. **宁缺毋滥**：凡拼写无法在上述权威来源中核实的词汇一律不收录（如布依语"轻""跑""露水"等暂缺）。
2. **修正壮语混入**：项目早期种子数据中混入壮语拼写（如 mwngz、gwn haeux、fwngz、sam/seiq/haj 等），已全部下线或改写为标准布依文（mengz、genl haux、fengz、saaml/sis/hac），修正清单见 `backend/src/scripts/seed-verified-data.ts`。
2.1. **第二批释义修正（依据《布依汉词典》词源学证据）**：joic 原标"橘子"实为"芭蕉"（原始台语 *kləəj，与泰语 กล้วย 同源）；jux 原标"橘子"实为"暴风雨"；waail 原标"岩"实为"坝"；doongl 原标"一起"实为"腌"。
3. **例句可溯源**：所有例句均摘自上述出版物原文，格式为"布依文（汉译）"。
4. **土语区标注**：数据以第一土语（望谟标准音）为主；第三土语特有词（如 slungz 床、hrangz 苦、sl/hr 声母例词）未收录，避免混淆。

## 五、导入方式

- **Excel 批量导入**：`data-import/` 目录下三个文件，通过 admin 后台「内容管理 → 对应类型 → 导入」上传（建议 upsert 模式）。
- **种子脚本**：`backend` 目录下执行 `npm run seed:verified`，数据与 Excel 同源（`backend/scripts/buyi-data-*.cjs`），并同步修正库中错误旧数据。
